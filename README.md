One line of weather, at most 140 characters, for a city that does not exist — written to make a bored commuter smile on the way to work.

## Entry

> Good morning, Grumplewick: 14°C with light drizzle, clearing by nine — and yes, the 8:15 bus is actually on time.

## How it works

`main.py` (Python 3 standard library only) writes the forecast line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

```sh
python3 main.py
```
